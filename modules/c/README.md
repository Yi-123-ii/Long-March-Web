# 同行 · 重走长征

v0.22.0，六站地图式剧情游戏。由仓库根目录 `journey.html` 进入；在根目录运行 `npm run dev`。与总站的事件、存储、导航接口见 [C接入说明](../../docs/C-INTEGRATION.md)。

地图按用户确认的山河长卷设计更新为暖纸底色、朱红路线和双页行军相册；站点与标签仍是真实按钮，保留锁定、已完成、独立章节进度、拖动缩放及沿曲线行进的红旗。新增5018于都导入影片，首进或重玩第一站时在相册后播放；中途继续与其他章节不重复播放。保留原声，字幕为用户确认的“小满，该出发了”，人物标为陈禾。影片支持暂停、跳过与失焦暂停；独立播放层不更改原故事节点、存档路径或解锁规则。素材与设计记录见 [地图更新说明](docs/map-ui-v022.md)。

六站与历史过场、会师尾声共141个节点，5处双选；保留选择回响和五条个人回忆。12条用户原声影片，V05/V06沿用确认的字幕，静图文字无朗读。地图按位置标站，可拖动缩放；跨站先由红旗沿路线行进，再翻开相册，保留柔和白光与光点。两段过渡都能用按钮或Escape跳过，尊重减少动态效果。鼠标小战士按用户新参考生成透明插画，仅精细鼠标显示，触屏保持原生操作。

每章结尾可重玩当前站、进入下一站、阅读对应长征纪事或在山河邮局写信。纪事使用现有 `#event=ID`，邮局使用已有的 `?event=ID#letter-form`，不自动填信或投递。重玩仅回到当前章合法起点；全剧末尾不显示下一站。

从游戏进入纪事或邮局后，可点击显式的“返回游戏，继续这一站”。返回会恢复原来的节点或结尾菜单；从地图出去则返回地图。跨过纪事再进入邮局也保留返回入口，普通独立访问B页面不显示游戏返回条。

只带当前资源，不带旧人物视频和被否决的TTS。图像、声音来源和提示词见 [SOURCES](SOURCES.md) 与 [图片提示词](docs/image-prompts.md)。原始素材本地备份，影片音轨完整保留；AI图片不是历史实拍或精确复原。

运行 `npm run check` 检查本模块。所有32种选择组合均能到达会师尾声；旧revision7/8进度按合法路径迁移到9，不补造选择。不要更改B模块存储，也不要给静图重新叠加退休配音。
