# 地图全屏与导航衔接

桌面首次进入使用等比铺满视口的地图画布，导航浮在同一张山河画面上。画面顶部通过半透明蒙版渐入，去掉固定纸色导航底、底部阴影和画布内边框，不使用重复山景或模糊填边。

路线、站点和红旗保留1180×620的原逻辑坐标。画布等比缩放时，这三层始终一起缩放。初次取景保留于都方向与顶部站点；“全图”切回完整容纳地图的模式，放大、缩小、拖动与后续跟随继续使用现有接口。镜头状态仅在内存中保存，没有新增或修改用户存储键。

夹金山标牌、顶部尾声标牌调整到不遮挡标题的位置。手机端仍使用可拖动地图与下方相册，标题区为导航留出空间，地图区域高度随屏宽适配，底部控件留在地图内。

修改局限于 `atlas-fullscreen.css`、`atlas-map.js` 的画布适配和初次取景，以及页面的样式/脚本缓存版本。其余板块、故事节点、素材和进度规则未修改。

验证：1440×900、1280×720、1920×1080、2560×1080、390×844实际截图，无页面横向溢出；各站点的屏幕中心与SVG路线坐标相差小于0.1px。逐页点击放大、全图，检查手机导航以及第一站进入、导入跳过、故事显示。52项C模块测试通过；30份浏览器脚本语法、资源与9篇史实检查通过。截图及坐标数据在忽略目录 `output/playwright/map-fullscreen-*`。
