# 后续影片接入要求

按用户确认，后续提供的视频均执行：

- 保留原片及原声；处理画面内 AI 生成水印，不覆盖原件。小范围角落插值只修补被标记挡住的区域，不宣称还原真实细节；不额外裁掉人物或改变运镜。保留原有 AI 来源元数据及“关于这一程”的 AI 创作说明。
- 以实际原声为准配流式字幕；不能识别台词时先请用户确认，不拿剧本猜测。支持多段 `captionCues`，停顿期间保留已显示文字，重播、暂停、跳过后按视频时钟同步。
- 角色名字放在对白框左上角原“心声”位置，视频、图片使用同一规则；不在画面角上另挂姓名牌。
- 用处理后视频的首末帧承接，检查接入位置、前后空间和人物一致性；不要留旧形象或有水印的过渡静图。
- 检查网页播放、字幕、姓名、重播、结束静帧与后续选择，保留其他站点解锁和书签；不擅自重置存档、扩写剧情或新增付费生成。

## v0.18：第二站梁叔补袖口

接入用户提供的 8180 镜头（文件标称6秒，实际容器6.080秒，视频6.016667秒；1280×720，145帧，可变帧间隔，平均帧率8700/361；AAC双声道44100Hz）。未强制转换为60fps或插帧。视频重编码后音轨直接复制，SHA256比对一致，视频帧数、时间戳与时长保持。

左上角水印修补区域为x12/y12/112×58，可能有轻微柔化。首末帧来自同一处理后镜头，作为 `liang-sewing` / `liang-sewing-hold`；原有相同剧情节点 `xj-sleeve` 改为影片，不插入或删除节点，保持storyRevision 9，现有路径及跨站书签继续有效。

用户确认台词：“别缩，针还没碰着呢。先缝三针，过了江再补。”字幕按四个短语分段流式呈现，时间依据音轨能量停顿初步划分，并非逐字语音识别。后续心声改为收回胳膊、跟队过江，避免重复旁述影片台词。
