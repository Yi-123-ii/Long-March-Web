# V4.7 精神传承：叙事脚本与史实核查

核查日期：2026-11-04。适用区域：`inheritance.html#legacy-bridge`，以及人物纪实顶部的一句衔接文字。

## 叙事意图与空间组织

主标题为“走过的路，留下的精神”。原来的三栏年份序列整体撤去，改为三个相互接续、构图不同的历史片段。顺序依据“判断方向—扶持同伴—关切群众”的叙事展开，不按事件年份排列。

- 遵义会议：红军遭受失利，如何正视问题、纠正指挥错误。左侧标题与右侧史实并置，先建立判断与选择的关系。
- 雪山与草地：以真实长征文物的展陈照片进入物资匮乏的处境，再读搀扶、背负病员和让马的具体行动。图像占据主要视觉空间，文字不写成空泛的意志赞歌。
- 半条被子：从战友互助转向军民关系。用原创的两片织纹图形呼应“分一半”的行动，图形不代表现存文物，不承担史料证明功能；史实由正文陈述。

暖纸底色保持连续，以赤红文字和细线提示精神凝练。没有三张重复卡片、强制滚动、长段固定定位或新增渐入脚本。静态文档默认显示全部文字，减少动态效果与禁用 JavaScript 时仍可完整阅读。

## 上线脚本与事实边界

### 片段一：危局中，敢于重新判断

正文记述第五次反“围剿”失败、长征初期受挫，以及1935年1月15日至17日中央政治局在遵义召开扩大会议、总结军事指挥教训、纠正错误和调整领导与指挥安排。

依据：任伟《遵义会议：中国共产党历史的伟大转折》，学习时报，2021-08-12，共产党员网转载。文中第三部分记载会议日期、军事路线讨论及领导与指挥调整。

原文地址：https://www.12371.cn/2021/08/12/ARTI1628761880703772.shtml

交叉核查：《遵义会议：生死攸关的伟大转折》，中华人民共和国国防部网站，2019年专题文章。搜索结果和页面资料确认会议日期、总结第五次反“围剿”失败与长征初期失利的中心议题；本轮工具直接读取该页面发生超时，故不以它作为唯一依据。

原文地址：https://www.mod.gov.cn/gfbw/gfjy_index/js_214151/4832355.html

页面“独立自主、实事求是，体现在正视失利、从实际出发寻找出路的行动中”为对已核实史实的编辑概括，不作为任何历史人物的直接引语。不把后来形成的领导分工全部压缩成会议当天一次完成，也不声称一次会议立即消除了全部困难。

### 片段二：险途中，彼此扶持前行

正文先以周广才皮带被割下一段充饥的事实写出缺粮，再写严寒和泥沼的困难，随后明确以“裴周玉在回忆中记下”引入亲历记述：战士搀扶或背负伤病员过河，作者把马让给掉队的病员，帮助通过险段。

文物依据：中国国家博物馆《红四方面军战士周广才在长征途中吃剩的皮带》。藏品页面记载该皮带1934年缴获，1936年7月红四方面军第三次过草地时，因为缺粮被吃去一段，余下部分保留。正文只采用最小必要事实，不补写对白与个人心理。

原文地址：https://www.chnmuseum.cn/zp/zpml/gmww/202105/t20210531_250098.shtml

依据：裴周玉《难忘的草地征程》，2014-01-21，中共中央党史和文献研究院网站，摘自中共中央党史研究室编《中共党史资料》。页面“渡河的困难”一节记载搀扶、背负病员及作者让马的经历。

原文地址：https://www.dswxyjy.org.cn/n/2014/0121/c244516-24182558.html

边界：该回忆网页起首年份与后续编制叙述存在需回查原刊之处，本页不援引其具体月份、团级人数、死亡人数及行军距离，不从单一个人回忆推导所有红军部队的同一经历。“信念便有了相互支撑的力量”是编辑概括，不是回忆原句。

### 片段三：自己的被子，也给乡亲留一半

正文记述1934年11月，三名女红军借宿湖南汝城沙洲村徐解秀家，与她合盖行军被；临行时想留下被子，在徐解秀不肯接受后将其剪开，留下一半。

依据：陈文广《半床棉被诉说８０多年前的军民情》，新华社，2016-08-23。报道采访徐解秀的孙子朱分永，记载借宿、合盖行军被、剪被留下的经过。

原文地址：https://www.xinhuanet.com/politics/2016-08/23/c_1119437229.htm

边界：正文不补写三名女红军姓名、未经确认的对白或剪被当日日期。报道亦记载原被后来被烧毁，页面因此只呈现抽象织纹图案，不以复原物件冒充原件。军民信任与同甘共苦的关系是编辑概括。

结尾：“雪山草地已留在历史深处，面对困难时的选择与担当，仍发生在今天。”人物区仅将顶部引言改成邀请读者关注人物面临的难题与持续行动。

## 读者可见文字与辅助阅读

- 主标题由一个二级标题呈现；三个片段各有三级标题及对应 `aria-labelledby`。
- 实拍图片使用描述文物外观的替代文本，图注标识文物身份与拍摄机构，不将现代展陈照片称为1930年代历史现场。
- 织纹图形标记 `aria-hidden="true"`，信息由相邻正文完整承担。
- 区域内没有外部超链接；完整历史来源保留于本文档。
- 原 `inheritance-v43.js` 中只撤去针对旧三栏时间线的观察器。该观察器在找不到旧节点时会中断后续弹层初始化；导航、开始阅读及六故事的业务代码不改。

原图与授权页：https://commons.wikimedia.org/wiki/File:Uneaten_remainders_of_two_belts_during_Long_March_at_MCPC_%2820240620094143%29.jpg

处理记录：从原图 `x=1250,y=1290,width=2032,height=1270` 裁取下方周广才皮带，完整保留该圈皮带、金属扣与编号2；等比缩小至1260×788、840×525并转换WebP。没有调色、锐化、重绘或抹除标记。图中看不到皮带背面的“长征记”，正文与辅助文本均不声称这三个字在该画面可见。派生图片沿用CC BY-SA 4.0。
