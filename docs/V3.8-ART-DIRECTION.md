# V3.8 题字艺术指导与资源说明

## 从排字变为题字

V3.7 的序章与尾声沿用 AR PL KaitiM GB 字形轮廓，并分别以22/25单位描边增重；该来源在原项目说明与路径逐项比对中可证实。字幅、基线和收笔节奏接近均等，书写气息仍取决于现成字库。

V3.8 两组标题分别作为固定文案的独立画面创作。内置 image_gen 根据本轮艺术指导生成，序章追加一次边缘/完整笔画修订，再进行透明通道、逐字识读及网页小尺寸校对。新图没有取用旧 SVG 的 path，也没有把字库描边冒充原创。它是 AI 辅助定制的题字作品，不是书法家人工手写墨宝、通用字体文件或可排任意文字的字库；不保证排他版权。最终提示词、生成ID与修订记录见 V3.8-IMAGEGEN-PROMPTS.md。

## 序章：有些路，值得一再回望

以深墨绿压在暖纸上，两行构图保留第一行的起势和第二行的回看。方折、切入与厚笔腹承担碑刻分量，斜行、飞白和外送笔锋提供行书速度。并未宣称图像具有一套可考据的碑帖书体；视觉成品更偏向带刀锋的奔放行书。

| 字位 | 实际艺术选择 |
| --- | --- |
| 有 | 长撇斜下，引入画面；月部收紧，作为起势而不做中轴对称。 |
| 些 | 上部压紧，下面二横形成连续上扬的小停顿。 |
| 路 | 右部开张，足旁收束，以大字幅和厚重转折作为第一行锚点。 |
| 值得 | 两字紧接、略压窄，节奏先收；保留亻、彳和直/日结构的辨识。 |
| 一 | 长横略向右上行，飞白顺笔势贯穿，成为两个词组之间的转折。 |
| 再 | 中宫较紧，纵笔下沉，给后两个字重新聚力。 |
| 回望 | 回的外框与内口保持区分；望的上部倾斜，下横向右外送，形成回看的余韵。 |

标题不再漂浮在单独色块内，而与既有路线山景共享纸色。说明文字收为较安静的褐色阅读层，以短朱线提示起读，不与题字争抢。桌面保留左字、中说明、右画关系；手机将正文移到题字下方，避免把六字第二行挤成不可读细线。

## 尾声：征途有尽，回响无穷

暖白墨色与深绿山川形成主次；前句蓄势，后句展开。两行四字分句在所有视口中由固定题字资源保持，不依赖浏览器随机拆行。标题放大后的笔锋也仍保留原生Alpha边缘，没有统一外描边、发光或阴影造假。

| 字位 | 实际艺术选择 |
| --- | --- |
| 征 | 彳窄，右部厚而上扬，斜切起笔承接全页的前行动势。 |
| 途 | 余部集中，辶的长笔横向承托前句，是第一行的连贯骨架。 |
| 有尽 | 有收窄而竖势明显；尽的捺向右释放，逗号留出短暂停顿。 |
| 回响 | 回重而开口明确，响左口小、右向舒展，避免连笔破坏识别。 |
| 无穷 | 无的撇捺张开；穷保留穴与力的轮廓，长收笔延入远山方向。 |

英文题记为次级索引，结束短文为再次落地的阅读点。761–1100px 把结束短文移到标题下方，避免90px侧栏导致逐字断行；小屏采用平衡换行。去掉前版锯齿多边形上沿，采用山景本身的层次收束。

## 真正可用的透明资源

目录 `assets/images/typography/v38/`：

| 文件 | 画布 | 用途 |
| --- | --- | --- |
| prologue-master.png | 1536×1024 RGBA | 序章透明母版 |
| epilogue-master.png | 1536×1024 RGBA | 尾声透明母版 |
| prologue.webp / epilogue.webp | 同上，无损Alpha | 网页直接使用的资源 |

这四个文件含真实Alpha，没有将黑底/棋盘背景画进图片，也没有用嵌入PNG的SVG伪称矢量。当前交付为透明栅格，没有承诺逐笔可编辑矢量；保持固定画布与完整资源，不再紧裁。h2 保留可访问中文全文，装饰图片 aria-hidden，标题仍可由屏幕阅读器读取。

独立审查统计：序章约65.86%、尾声约57.49%像素为Alpha=0；PNG与无损WebP的Alpha逐像素一致，实际合成结果一致。尾声最左主笔约有16px安全余量，因此CSS未使用overflow:hidden裁题字。1536px母版在最大650 CSS px标题和常用2x密度下仍可直接使用；超高密度或印刷扩展需另作更高分辨率或真正矢量版本。
