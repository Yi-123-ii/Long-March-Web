## 用户提出的横线缺陷的根因与处理

原概念渲染把标题、导航和两条装饰横线烘焙进单张图。实际网页首屏没有使用整张图作背景，而是仅使用右侧无 UI 内容的场景裁片 `home-cinematic-scenery.webp`；书法二字作为独立透明资产 `home-title-brush.webp`；其他界面控件由 HTML/CSS 渲染。无横跨导航或首屏底部的装饰边框。
