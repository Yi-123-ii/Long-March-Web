# C 交互更新 v0.16

2026-11-02。按用户“小红军角色建模参考”更换鼠标角色，增加跨站地图行进和章节结束接口。本轮不改剧情、人物原声或任何A/B功能文件，不生成新视频或配音。

## 行为

- 精细鼠标显示透明小红军插画，点击热点有小菱形；图片不拦截点击，靠近窗口边缘自动换侧。键盘Tab、失焦和触屏隐藏角色并恢复原生指针。移动反馈为轻微整体起伏，不冒充逐帧走路动画。
- 从故事结尾或地图进入不同章节：先回地图，红旗沿已定义路线由当前位置行进到下一章，再翻开原相册。行进采用距离采样和首尾缓动；有双地名的赤水—金沙江章从赤水进入、从金沙江离开。可点击“跳过行进”或按Escape，再单独跳过相册；减少动态效果时直接到达，不播放行进。
- 动画期间不接受第二次选站或推进，尚未到达时仍保存原站合法进度。切换后延用真实选择，重玩只回到本章起点。
- 结尾提供下一站、重玩本站、对应纪事与对应邮局写信页，并保留返回地图。最终尾声不提供下一站。地图选中下一站不会改变刚完成章节的外链。
- 纪事与邮局是同标签普通链接，沿用 `#event=ID` 及 `?event=ID#letter-form`；不预填、提交留言或改写B数据。
