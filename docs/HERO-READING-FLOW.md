# 首屏标题与阅读入口调整

用户进一步选择与长征纪事一致的“文字＋下箭头＋细下划线”首页入口，替代此前的纸卷样式。首页不再加载纸卷CSS，入口背景透明、保留米白字和键盘焦点，仍跳转到 `#prologue`。

长征纪事移除大标题上方的小字，将原标题下说明改写后移至“那些走过的路”右侧。大标题与入口按钮水平居中，按钮紧接标题，不再被说明挤到首屏底部。题字和雪山插画保留。

山河邮局移除标题上方的小字，将原右侧短句放到标题下方居中。首屏最小高度扣除共享导航高度，确保“写下留言／我的留言”在往下滚动后出现。表单、标签页ID、投递流程及留言存储未修改。
