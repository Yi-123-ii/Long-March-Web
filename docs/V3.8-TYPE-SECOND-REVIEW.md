## 笔势与节奏

两张图都已具备大笔触的粗细变化、斜势、飞白、收笔分叉与不等宽构形；不再呈现 V3.7 现成轮廓统一描边的外观。序章第一行三字开阔，第二行六字压紧，重点落在“有、路、望”；尾声以四字对四字和“途”“穷”的长笔形成呼应。

当前风格更偏奔放行书与干笔飞白，刀刻碑拓感主要来自尖锐转折和边缘破口。没有必要为了增加纹理再次大幅生成，以免破坏已经正确的结构。两张图的粒度略有差异：序章墨色有较细碎的肌理，尾声较像实色笔画配少量飞白；这是可选的风格统一项，尚不构成必须修正的问题。

## Alpha 与裁切

使用浅纸色 `#f1e7d7`、深绿 `#0f2523`、白色和棋盘底直接 Alpha 合成检查，未见纸面矩形、假棋盘背景、明显白边或可见的宽泛色晕。源图在查看器黑底上的暗淡或发光外观不足以判断其在产品底色上的实际效果，合成图用于本轮判断。

Alpha=1 的极弱边界残留不等于有效笔画触边，也不支持认定有截笔。最大 Alpha 为254表示主笔接近不透明，并不影响确认真实透明背景。若后续工具按“任意非零 Alpha”自动裁边，可能因这些残留保留多余空白；这是处理注意事项，无需为当前视觉效果修改源图。

尾声“征”的最左笔锋距离边缘只有 16 像素，空间比序章紧，但当前完整可见。不宜再用裁切或 cover 缩放压紧它；最终页面中的尺寸、分行派生图与容器溢出仍需另外验收，本轮源图通过不替代页面检查。
