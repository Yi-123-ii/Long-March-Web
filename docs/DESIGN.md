# 纪事图文与字体设计

参考页面：[故宫名画记](https://minghuaji.dpm.org.cn/)。只研究它让题字、图像和常规文字分层的方式，不复用页面源代码、图片、标识或版式。本站继续围绕长征纪事组织顺序阅读，保留自身山河插画和青绿山色。

## 本版方向

- 配色：纸白 `#f9faf6`、雾绿 `#eef1ed`、松墨 `#263d36`、石绿 `#69786f`、淡青 `#cdd6ce`、暗红 `#973e39`。
- 题字：Zhi Mang Xing（志莽行书）用于首页与邮局大标题、品牌和纪事首尾阶段。替换原来圆厚的 Ma Shan Zheng，用舒展的笔势表达启程与抵达。
- 阶段及短标题：Noto Serif SC（思源宋体）600字重。替换原来的文楷，靠笔画粗细、衬线与字重建立层次。年代数字采用 Oswald；长正文与操作文字采用清晰的系统字体。
- 字号：桌面题字约88—114px、栏目题字62px、首尾阶段64px、常规阶段约34—44px、年代31px、摘要14px。手机按可用宽度调整，正文不使用行书。
- 结构：左侧保留年代索引；右侧按时间排列阶段。实色纸面上左侧文字、右侧独立插画，手机改成上下排列。插画不降低透明度，文字不叠在图片上。

审视后保留单列时间顺序和清晰的阅读入口，撤掉重复印章与淡照片底图。首尾题字标记启程与抵达，其余阶段使用一致的宋体标题。八幅解释性主题插画只承担地点识别与氛围表达；详情的现址照片、时间线、作者与许可独立保留。生成工具与完整提示词见 `docs/ILLUSTRATIONS.md`。

## 字体授权与维护

三款字体均来自 Google Fonts 的开源发行，使用 SIL Open Font License 1.1。许可原文和来源说明保存在 `assets/fonts/`。网页只加载本地 WOFF2 文件，不请求 Google Fonts/CDN。

字形子集覆盖当前用于艺术标题、阶段名称和数字的固定文字。新增这类文字时运行 `node tools/prepare-fonts.mjs` 重新生成子集；此脚本仅用于素材准备，访问网站不需要运行它或联网下载字体。没有覆盖到的新文字会使用系统回退字体，不会显示为空白。
