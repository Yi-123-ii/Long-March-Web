# 纪事图文与字体设计

参考页面：[故宫名画记](https://minghuaji.dpm.org.cn/)。只研究它让题字、图像和常规文字分层的方式，不复用页面源代码、图片、标识或版式。本站继续围绕长征纪事组织顺序阅读，保留自身山河插画和青绿山色。

## 本版方向

- 配色：纸白 `#f9faf6`、雾绿 `#eef1ed`、松墨 `#263d36`、石绿 `#69786f`、淡青 `#cdd6ce`、暗红 `#973e39`。
- 题字：“山河为卷，脚步为证。”采用原创飞白书法题字；“那些走过的路”采用结合山峰、小路、脚印与红旗的图形艺术字。两者保留可访问的真实文字，不复制用户参考图中的原句或字形。生成记录见 `docs/TITLE-ART.md`。
- 当前紧凑绿色品牌：品牌副标题“循着来路，读懂远方”统一为实色绿色，字形使用 `assets/images/titles/brand-tagline-v2.webp`，桌面宽108px、手机84px（极窄屏80px）。真实文字保留在品牌链接内供辅助技术读取。
- “山河印记”主标题改用重新绘制的克制松绿色字形 `assets/images/titles/brand-name-v3.webp`，没有沿用红金色及强烈海报笔势。主标题桌面宽118px、手机94px（极窄屏90px）；左侧水彩插画同步缩到42px、手机30px（极窄屏28px）。此版先作本地预览。
- 首页邮局入口改为圆润的信封主题按钮：暖纸色底、双层邮边、手绘信封与火漆印、圆形箭头；悬停时信封微抬，键盘焦点清晰可见，减少动态效果时停用位移动画。按钮仍直接进入邮局。
- 九个阶段名称采用独立绘制的粗笔画、方折、飞白艺术字，列表和详情共用同一幅题字。保持深松墨色，避免把参考图的浅色文字直接叠在浅背景上。真实标题仍可被辅助技术读取，图片失败时回退文字。题字与提示词见 `docs/STAGE-TITLE-ART.md` 及 `docs/REVISION-ART.md`。筛选和阶段文字回退使用站酷小薇体；品牌保留志莽行书。邮局页采用红金艺术字与高铁、城市、田野、风机剪影；首页邮局入口采用绿色手绘字、信封与纸飞机。
- 小字：简介、地点、年月、栏目说明和正文使用 LXGW WenKai TC（文楷），按钮及导航采用思源宋体600字重，年份采用 Oswald。调整的不只是字号，也包括小字的实际字形。
- 尺寸：桌面阶段题字高70px、详情78px，手机分别58px和62px，限制在容器宽度内；年份32px、简介17px、地点及年月15px、阅读入口13px。手机简介16px。
- 结构：保留单列时间顺序。每幅插画铺满阶段背景，图片本身不透明度约80%；文字一侧采用浅色渐变遮罩，保留背景的山河轮廓。手机遮罩改为由上至下，画面仍是阶段背景。
- 封面与纪事栏目的衔接：只在大封面底部叠加向页面雾绿色渐隐的遮罩，不改变题字和画面上部；封面正文和底部年份按自然流分开排布，避免矮屏时重叠。各阶段插画恢复原来的矩形背景、局部护字遮罩和底边线，不做四周渐隐。

审视后撤掉独立插画栏，不再把画面与文字分成两块。只让背景透明，文字和按钮始终实色。图形艺术字服务于“走过的路”的含义，避免挪用参考图的足球、奖杯等无关元素。九幅阶段插画仍是解释性绘画；详情的现址照片、时间线、作者与许可独立保留，见 `docs/ILLUSTRATIONS.md` 及 `docs/REVISION-ART.md`。

## 立体信箱与投递

当前采用立式深绿色金属邮筒，独立投信口、下部带锁取信门和一体底座更接近实际公共邮箱。箱体使用本地透明 WebP，保持静止；信封由遮挡层逐步收入原有投信口，最后出现“已投递”反馈，总时长约3秒。撤去额外叠加的翻板和铰链，避免细杠横在信封前。取信门和箱体均不参与动画，侧栏和投递反馈复用同一模板。不依赖3D组件库。

留言先成功保存，再播放动画；失败时保留输入并提示。可跳过动画；减少动态效果设置下直接呈现完成状态。仅操作当前浏览器本机留言，不发送真实邮件。首页题字与“那些走过的路”沿用已确定版本。

## 字体授权与维护

现用字体来自 Google Fonts 的开源发行，均使用 SIL Open Font License 1.1。许可原文和来源说明保存在 `assets/fonts/`。网页只加载本地 WOFF2 文件，不请求 Google Fonts/CDN。文楷与思源宋体按字形分组，浏览器按需加载。

字形子集覆盖当前用于艺术标题、阶段名称和数字的固定文字。新增这类文字时运行 `node tools/prepare-fonts.mjs` 重新生成子集；此脚本仅用于素材准备，访问网站不需要运行它或联网下载字体。没有覆盖到的新文字会使用系统回退字体，不会显示为空白。


## 2026-10-24 插画回应与信件仪式

保留原封面题字与阶段背景，下沿渐变不动；新增上沿85—165px淡入，撤去导航与封面之间的分隔线。阶段背景在鼠标悬停及键盘焦点进入时放大至1.045倍，文字保持不动，减少动态效果时停用。参考本地《汉口非遗图鉴》的卡片图片反馈思路，未复制其素材。

邮票选项为于都启程、铁索长桥、雪山草地、今日山河，前三枚围绕长征，后一枚以灯火与城市呼应当代。邮票使用暖纸色齿孔外缘及绿色选中状态。三位原创新绘小邮差分别用于信箱旁、空列表和投递提示，不作为选择对象。完整信纸先供滚动阅读，用户确认后才保存并开始两折、装封、封口、投入静止绿色信箱的过程。
