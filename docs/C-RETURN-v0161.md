# 纪事、邮局与游戏往返 v0.16.1

2026-11-02。用户要求跨栏目后能明确返回并继续游戏，补齐v0.16只有外链和浏览器后退的缺口。

- C外链带 `from=journey&view=story` 或 `view=map`，保留原纪事 `#event` 和邮局 `event` 参数。
- 在纪事、邮局各增加一行 `modules/c/assets/journey-return.js` 引用。B业务脚本、正文、导航源标记和存储约定不改。适配器仅在来自游戏时启用，普通独立访问不显示返回条，也不加载它的CSS。
- 显示底部返回条，纪事详情弹窗的顶部另外放置返回按钮。B两页之间的链接保留来访上下文；导航中的“重走长征”也返回原进度。
- 离开前保存现有C进度，并在C独有的 `longmarch-c:return:v1` 会话键中保存该标签的有效路径快照。不会写入B键或改动信件正文，不发送留言。
- 返回故事时直接恢复原节点与结尾菜单，不重开相册、不从章节起点重玩；返回地图时保留原进度并显示地图。读取后清除一次性的返回参数与会话快照；会话存储不可用时沿用原有本地存档。
- 返回地址由适配器的同源资源位置构造，不能传入任意外部返回地址。GitHub Pages仓库子路径受到测试覆盖。
- 返回后再次打开外链也继续使用当前章的事件ID，修正直接恢复早于接口脚本初始化时默认指向于都的问题。
