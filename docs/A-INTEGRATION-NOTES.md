# A 成员首页 V1 整合笔记

## 本轮实现

1. 保留原 B 内容与功能；将原 B `index.html` 复制为 `chronicle.html`。
2. 以新 `index.html` 作为总站首页；电影感首屏、按钮与四章节入口均是单独结构。
3. 将 B 两页的导航替换为五栏目公共导航，公共导航样式由 `site-shell.css` 管理。
4. 添加精神传承内容初版，从 B 的 `data/contemporary-cases.js` 安全创建 DOM。
5. 添加透明的 C 模块集成占位页，不提供虚假的游戏控件。

## 首屏横线处理

原 AI 概念图将文字、按钮、导航线绘制在同一张图中，这种图不能直接作为真实网页。现在只截取左侧文字区域以外的山河画面，且移除含原导航/页脚的位置。新 `home-cinematic-scenery.webp` 内**没有**原本的界面线条、导航或文字。首页导航、按钮和副标题由 DOM/CSS 渲染；「长征」二字使用独立透明书法图片，并在 h1 中提供可访问文本。没有跨屏水平分隔线。

## B 协作注意

`chronicle.html` 和 `post-office.html` 新增加载 `assets/css/site-shell.css` 和 `assets/js/site-nav.js`；不改 B 原功能脚本与 localStorage 键。整合时注意在 B 原 CSS 之后加载 shell CSS，避免破坏旧页面排版。

## 已知限制

- 这轮运行时校验能验证代码语法、文件路径、HTTP 200，但当前自动化浏览器环境拒绝访问本地网页，因此**尚未独立验证各窗口截图和键盘交互**。
- `journey.html` 尚无 C 代码；精神传承缺乏现代纪实照片。
- 首页背景来自概念图裁剪，右侧构图与不同比例屏幕仍需真实浏览器视觉审查。
