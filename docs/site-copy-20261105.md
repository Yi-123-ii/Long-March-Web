# 全站短文案复核 · 2026-11-05

本轮覆盖首页、长征纪事、重走长征、精神传承和山河邮局，包括弹窗、保存提示、地图章节导语与分支结尾。

- 短文案不使用句号分隔，结尾也不加句号；按语意重组表达，避免把一串短句原样换成逗号
- 卡片介绍具体内容，操作提示说明当前状态和下一步，人物与实践导语保留明确的行动对象
- 长篇历史正文、人物故事和三段写信引导仍按语意自然分句，保留事实范围和确定程度
- 141 个剧情节点的编号、路线、媒体及存档结构未变，12 段配音的原词句与字幕时间点未变
- 六组案例的资料出处、图片信息、日期与数字已和修改前对照，九篇纪事的史实内容未变

复核：`npm run check`（含 525 项短文案检查）、案例生成同步检查、76 项现有测试及字体覆盖检查通过。实际 Edge 浏览器在 1440 与 390 像素宽度检查五个页面、六组故事详情、寄信各阶段、代表性剧情和说明弹窗；未见短文案残留句号、横向溢出或脚本异常。

界面和排版的复核仍须结合实际页面，自动检查不能替代逐段通读；长篇叙事正文及读者自行写入的留言不按短文案规则删改标点。
