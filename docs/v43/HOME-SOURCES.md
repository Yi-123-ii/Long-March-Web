# V4.3 首页序章依据

核对日期 2026-11-03。序章以各路红军战略转移概括长征，时间范围写为1934至1936年。时间线首节点明确为中央红军于1934年10月离开中央革命根据地，不将其写成所有部队的共同起点。1936年10月会宁、将台堡等地先后会师，按三大主力胜利会师概括。

- 中共中央党史和文献研究院《中国共产党一百年大事记》，中央网信办 2021-06-28 刊载。核对中央红军出发、1935年1月遵义会议和1936年10月22日将台堡会师。[原文](https://www.cac.gov.cn/2021-06/28/c_1626466231109545.htm)
- 国防部《奋斗百年路 启航新征程丨会宁会师 长征胜利》。核对会宁、将台堡等地会师及长征胜利的历史标志。[原文](https://www.mod.gov.cn/gfbw/tp_214132/tsjs/4878949.html)
- 中央纪委国家监委《读文献 学党史｜遵义会议的伟大转折》。核对遵义会议的时间与历史处境。[原文](https://www.ccdi.gov.cn/yaowen/202103/t20210309_237465.html)
