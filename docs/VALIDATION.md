# 本轮本地验证

测试日期：2026-10-22。使用 Playwright 驱动 Chromium，本轮未在比赛指定的 Chrome 129 中实际运行；最终整站仍需在该版本确认。

## 已检查

- 1920、1440、720、390 像素宽度下两个页面均无横向溢出，并检查了桌面和手机截图。
- 纪事：八段内容加载；年份筛选；搜索无结果与重置；史实弹窗；前后事件切换；Escape 关闭；游戏可用的事件深链接。
- 邮局：空白输入提示；草稿保存与刷新恢复；投递完成；本机留言持久化；展开查看；取消删除与确认删除；文本导出。
- 异常情况：存储写入失败时提示且保留输入；损坏的本机数据不导致页面崩溃；连续两次提交只保存一次。
- 用户输入按纯文本展示；模拟 HTML 标签不会被作为图片等元素执行。
- 减少动态效果偏好下跳过投递动画；浏览器控制台未发现页面脚本错误。
- 本地资源引用、事件数据完整性和浏览器脚本语法检查通过。

截图及操作记录在本机 `output/playwright/`、`.playwright-cli/` 中，已由 `.gitignore` 排除，不需要上传这些测试产物。测试留言已从专用测试浏览器清除。
