# 重走长征首屏延展

进入板块先显示无标点的两行题字“循迹山河 / 重走长征”，向下滚动后进入原版互动地图。新山景向上延伸并淡化到原导航下方，保留原题字的深红色。

原地图的 terrain-v022.webp、atlas-route.js、atlas-map.js、剧情脚本及原样式文件没有修改。原相册卡片的 HTML、照片、日期、史实入口、继续按钮，以及站点坐标、红旗、缩放、目录、剧情动画和存档均保留。只删除此前要求移除的右下角说明框，并将旧的地图小标题换成首屏大标题。

新增资源：

- modules/c/assets/atlas/terrain-extension-v1.webp：以内置 imagegen 向上延展原地图的山景。
- modules/c/assets/atlas/heading-eight-v1.svg：内置 imagegen 题字的自包含 SVG 透明轮廓，使用原题字取样色 #750200；原始生成稿中的绿色不用于页面。
- modules/c/assets/journey-opening.css 和 journey-opening.js：仅管理首屏、背景接续与滚动入口。

1440×900、1280×720、1920×1080 和 390×844 下，对照原地图验证了相册位置与样式、地图尺寸、路线、所有站点状态、照片和文字；坐标误差小于 0.01px。验证相册打开、影片跳过、进入剧情、返回地图、缩放和全图功能。

绘图输入为原 terrain-v022.webp，提示要求向上延展山峦云海，保留下半部地标布局，无文字、分隔带、边框或额外人物。正式地图继续使用原始 terrain-v022.webp，生成图只作为首屏延伸和接续背景。
