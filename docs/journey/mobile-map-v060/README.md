# 手机地图与相册布局优化

## 设计和改动

手机端原先将独立缩放的互动地图直接拼在全屏延伸背景上，相册上方出现河岸横切、背景重复及透视错位。

保留现有山河长卷、红旗、人物照片和旧相册材质；在 600px 及以下采用连续纸面，使地图上下边缘自然淡入背景。地图与相册之间不再露出另一张放大的山水背景。

- 色彩沿用纸面 #f1dfbd、正文 #6a3825、题字 #8c291d、书脊 #c39b65
- 字体使用项目既有字体；地图标题 18px，相册标题 20–22px，提示文字 12px
- 默认手机缩放从 1.8 调整为 1.25，保留可拖动、缩放和全图模式
- 默认显示更多路线；非选中站点隐藏地图上的日期，选中站点和书页仍展示日期，减少标签覆盖
- 地图工具栏改为独立的正常文档流，触摸区域不小于 44px
- 目录在工具栏下方展开、居中，限制高度，可滚动，不越过手机边缘
- 相册人物照片不再被拉成长条；地点和章节信息在右页，按钮及首次体验说明横跨书页下方
- 新样式集中在 atlas-mobile.css，仅手机断点生效；桌面保留原相册浮层和地图比例
