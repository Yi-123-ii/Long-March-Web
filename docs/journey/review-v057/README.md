# 地图史实访问与返回（最终交互版本 059）

## 最终行为

以用户最后明确的要求为准：

- 地图左下角“读这一程的史实”保存故事状态、选中站点、缩放和地图滚动位置
- 文章右上角 ×、Esc 和正常结束阅读只关闭文章，回到长征纪事列表，不导航至游戏
- 底部提示为“继续浏览长征纪事板块　返回游戏地图　×”，沿用全站浅色底部提示样式
- 显式点击“返回游戏地图”才回到之前地图，并恢复地图位置和游戏进度
- 底部提示的 × 只隐藏提示，不删除存档；文章关闭时不重新插入已经隐藏的提示
- 邮局对应文字为“继续浏览山河邮局板块”
- 首页普通导航不创建游戏返回访问标记，站末的纪事和邮局返回继续使用 story 上下文

移除了 057/058 版本将文章关闭拦截为返回游戏的处理。保留地图访问保存和显式返回链接，不得按早期理解恢复关闭拦截。

## 修改边界

C 模块 site-integration、journey-return、atlas-map、yudu-game，以及三个 HTML 入口脚本缓存版本。journey-return 版本为 059。不修改纪事正文、文章脚本、剧情媒体、配音或永久存档格式。
