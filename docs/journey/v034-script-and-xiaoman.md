# 六站剧情同步与小满配音

发布整合版：v0.38，剧情存档编号 13，2026-11-06；由v0.34对白预览整合最新main而来。

## 剧情来源与保留范围

依据用户确认的《重走长征路-完整剧情润色稿-20261106》，同步六站图片文字、玩家选项及赤水、金沙江、泸定桥和北上过场。补入湘江伏低等待、两条过江支线、遵义门口集合、湿衣上山、草地粮袋、腊子口后方等待与战斗后的通行、吴起展开行装等段落。

五组主要双选分支保持不变。已有剧情影片全部保留，包括吴起记事线的“还有他家那棵枣树，也写上吧。他自己老爱说。”。ZY-04试袖口、收针线明确采用图片。缺少成片的预留位置继续使用图片文字，不自动生成或付费。

6203遵义陈禾旧信影片使用main已接入的版本，保留三段源片播放：`zy-b-question`播放0—2.15秒后等待`zy-b-answer`；小满回答后，`zy-b-advice`播放2.15—5.02秒，再由`zy-b-paper`播放余段。字幕沿用main的原视频时间轴，三句为“你打算写什么？”“那就先收着吧。”“纸别挨着火。”，提问和回答不连播压过玩家选择。

本轮保留main已有的湘江伏低、遵义腾位置、遵义旧信、赤水转场和夹金山捆铺盖成片及配套图片，不再引入预览分支里重复的旧信导出文件。夹金山三段视频按源片2.10秒、9.20秒等待两次玩家提问，两条小满录音播放后继续原片。所有影片继续使用原有角色声音。

## 小满语音

三份用户提供的即梦WAV，分为29个独立MP3，位于`modules/c/assets/audio/xiaoman-v034/`；`manifest.json`记录原文件、切分区间、台词与时长。31个剧情节点复用29条录音：自报姓名在不同路线复用，其余按各自语气和情境对应。台词XM01以用户确认的实际原声“我能站得住，你先把包抱稳。”为准。

玩家选项本身不播放声音；点击回答后，进入小满对白节点才播放。旁白、观察、心声和历史页签不配音。视频人物继续使用影片原声，不替换陈禾、梁叔、陆生的音色。

暂停、回看文字、声音弹窗、页面失焦会暂停配音；返回上一幕、切换节点、回地图会停止旧配音。人物音量同时控制视频原声和小满语音。自动阅读等待录音结束；手动可跳过语音。音频加载失败时保留完整文字与继续入口。

## 旧进度与队友接口

保留同一个C模块存档键。`story-legacy-v010.js`保存最新main有效图结构，`story-legacy-v011.js`与`story-legacy-v012.js`保存此前已配音预览图结构，连同原有v009结构迁移7—12版存档；从真实路径还原选择，不相信序列化的选择字段。独立站点书签、未来已解锁站点和长征纪事／山河邮局返回快照均迁移到13版。

本轮不更改其他组员的页面、事件ID和写信接口。开发服务器仅新增MP3 MIME类型。静态托管仍使用原入口`journey.html`跳转到C模块。
