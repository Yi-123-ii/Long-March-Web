# V3.8 首页与主分支整合记录

整合日期：2026-11-01。基线提交：`2f94801`。

## 变化

首页改为队友 V3.8 的完整首页，原长征纪事移至 `chronicle.html`。五个页面采用统一导航，并接入队友的题字、本地字体和传承页。`journey.html` 保留尚未接入游戏的状态说明。

旧的首页纪事锚点和事件链接转至新纪事页。查询参数、事件编号和锚点保留；首页自己的序章、栏目和返回顶部锚点照常使用。

## 保留

以现有主分支为准，保留 `assets/js/storage.js`、`letter-backup.js`、`post-office.js`、`chronicle.js`，以及所有纪事、传承和邮票数据。原留言存储键及备份结构不变。

队友包中的写信区小邮票会回退主分支后来的修改，因此本次使用主分支的独立写信插画、对应样式和邮局脚本。邮票仍在后续步骤选择，不提前占据写信区。

纪事日期、来源和艺术字保持原版本。未包含此前已撤销的文案润色。

## 留言影响

同一浏览器、同一线上域名下，原有留言和草稿仍按原键读取。更新代码不执行站点存储清除或数据迁移。不同浏览器或不同本地端口之间仍需要备份、导入。

## 验证范围

运行原有资源、脚本及史实结构检查；运行九项留言保存与备份测试；增加旧纪事链接的兼容测试。另检查本地及上线后的五页和实际资源路径。

本次没有重新认定队友历史截图、字体审计和赛事合规报告的全部结论。截图与原始比赛材料未加入线上仓库。新增游戏、正式比赛提交材料和跨浏览器云同步均不属于本次整合。

## 回退

本地 `backup/pre-v38-20261101` 分支保留整合前的主分支。需要回退线上版本时，可通过撤销整合提交发布恢复，不需要重写主分支历史。
