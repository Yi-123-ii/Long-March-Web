# 纪事与邮局的阅读往返

纪事详情的邮局链接携带 `event` 和 `readFrom=chronicle`。邮局仅在来源标记正确且篇目存在时显示返回提示，并在投递完成后提供相同入口；普通访问和仅恢复草稿均不会误显示提示。

返回目标固定为同目录的 `chronicle.html#event=篇目编号`，通过 `resumeReading` 触发一次性恢复。离开纪事时，在当前标签页的 `sessionStorage` 保存篇目、弹窗滚动位置、页面滚动位置、年份筛选及搜索词。恢复后移除一次性参数，正文和图片就绪后复核滚动位置；用户已开始操作时不再调整位置。存储不可用或记录损坏时，返回链接仍可打开原篇目。

从重走长征进入的访问保留原有游戏返回上下文，将两个返回入口合并到同一提示栏，避免浮层互相遮挡。留言的自动保存和本地投递机制保持原样。

验证覆盖桌面和手机上的九篇纪事往返、位置与筛选恢复、输入后立即返回的草稿保留、普通访问与无效篇目、游戏入口共存、投递完成后返回，以及会话存储被禁用的情形。原有留言存储及游戏返回的13项检查通过。
