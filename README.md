# 山河印记 · B 模块

长征主题参赛网页的两个栏目：**长征纪事**、**山河邮局**。本目录可独立预览，也可交给 A 整合进总站。

## 仓库与在线访问

代码仓库：[Yi-123-ii/Long-March-Web](https://github.com/Yi-123-ii/Long-March-Web)。

网页可以直接部署至 GitHub Pages，不需要运行 Node.js 服务。启用 Pages 并部署成功后，默认地址为 `https://yi-123-ii.github.io/Long-March-Web/`；邮局地址在其后添加 `post-office.html`。该地址在部署成功前不能作为可用链接分享。

配置方法及私有仓库限制见 [部署说明](docs/DEPLOYMENT.md)。

## 开始预览

Windows 可双击 **`开始预览.cmd`**，会启动服务并打开浏览器。预览时保持该窗口开启。需要已安装 Node.js。

安装 Node.js 18 或更高版本后，在此目录运行：

```sh
npm run dev
```

浏览器打开 **http://127.0.0.1:5173**。不需要安装依赖。停止服务时按 Ctrl+C。

也可以直接打开 `index.html` 查看页面；建议用上面的本地服务测试留言，避免浏览器对本地文件存储的差异。

## 已包含

| ----------------------------- | --------------------------------------------------------------------------------------------------- |

## 留言保存方式

- 留言只在**当前浏览器、当前网站地址**的 localStorage 保存，不发送邮件，也不上传服务器。
- 更换设备、浏览器或站点地址，不会自动带走数据；清除网站数据可能丢失。可使用页面上的文本导出。
- 不建议在公用电脑输入私人信息。同一浏览器配置中访问此地址的人可查看已存留言。
- 草稿最多 2000 字，署名最多 20 字，最多 200 段留言；达到上限会提示先导出、再自行删除。
- 与游戏分开使用 `longmarch-b:*:v1` 存储键，不会清除其他模块记录。

## 比赛实现约束

已依据本地《2026年“零杯”网页设计大赛选手手册》选择原生 HTML/CSS/JavaScript 实现，未使用 Bootstrap、Element 等预设样式组件库、现成网页模板或游戏引擎；没有后端服务依赖。查看史实原文时才跳转外部网站，页面及图片均保存在本地。

首屏插画为 AI 辅助创作，页面已标注；不是历史照片。若组委会另有 AI 素材补充要求，提交前应据此调整。手册要求的完整版/匿名版、队员信息和最终打包，由全队整合时补齐。

## 文件与交接

- `assets/css/base.css`：公共字体、颜色、导航、按钮、弹窗。
- `assets/css/chronicle.css` / `post-office.css`：两个栏目的样式。
- `assets/js/storage.js`：本机存储，校验异常数据并处理写入失败。
- `assets/js/chronicle.js` / `post-office.js`：交互逻辑。
- `data/events.js`：历史内容与来源，可集中修改文字。
- [整合说明](docs/INTEGRATION.md) · [资料与素材来源](docs/SOURCES.md)。

不含 A 的首页/精神传承页面与 C 的地图游戏；当前顶部导航仅连接已实现的两个栏目。

## 依赖及用途

**运行依赖：无。** `server.mjs` 仅用 Node.js 内置模块提供本地预览，不参与网页交互，不构成后端业务。`tools/check.mjs` 使用 Node.js 内置模块检查脚本语法、本地资源引用和事件资料完整性。制作素材时用 Sharp 做图片格式转换；它不是作品运行依赖。预览测试使用 Playwright CLI；不随作品加载。
