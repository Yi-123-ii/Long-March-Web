# 山河印记 · B 模块

长征主题参赛网页的两个栏目：**长征纪事**、**山河邮局**。本目录可独立预览，也可交给 A 整合进总站。

## 仓库与在线访问

代码仓库：[Yi-123-ii/Long-March-Web](https://github.com/Yi-123-ii/Long-March-Web)。

已通过 GitHub Pages 公开上线，无需安装软件或登录 GitHub：

- [长征纪事](https://yi-123-ii.github.io/Long-March-Web/)
- [山河邮局](https://yi-123-ii.github.io/Long-March-Web/post-office.html)

Pages 从 `main` 分支根目录部署。后续推送会触发更新；本地预览不影响线上网站运行。

配置方法及私有仓库限制见 [部署说明](docs/DEPLOYMENT.md)。

## 开始预览

Windows 可双击 **`开始预览.cmd`**，会启动服务并打开浏览器。预览时保持该窗口开启。需要已安装 Node.js。

安装 Node.js 18 或更高版本后，在此目录运行：

```sh
npm run dev
```

浏览器打开 **http://127.0.0.1:5173**。不需要安装依赖。停止服务时按 Ctrl+C。

也可以直接打开 `index.html` 查看页面；建议用上面的本地服务测试留言，避免浏览器对本地文件存储的差异。

## 留言保存方式

- 留言只在**当前浏览器、当前网站地址**的 localStorage 保存，不发送邮件，也不上传服务器。
- 更换设备、浏览器或站点地址，不会自动带走数据；清除网站数据可能丢失。可使用页面上的文本导出。
- 不建议在公用电脑输入私人信息。同一浏览器配置中访问此地址的人可查看已存留言。
- 草稿最多 2000 字，署名最多 20 字，最多 200 段留言；达到上限会提示先导出、再自行删除。
- 与游戏分开使用 `longmarch-b:*:v1` 存储键，不会清除其他模块记录。

## 比赛实现约束

已依据本地《2026年“零杯”网页设计大赛选手手册》选择原生 HTML/CSS/JavaScript 实现，未使用 Bootstrap、Element 等预设样式组件库、现成网页模板或游戏引擎；没有后端服务依赖。图文纪事可在站内完整阅读，页面及图片均保存在项目中；资料依据收在折叠注记，读者不需要跳往外站补齐正文。

首屏插画为 AI 辅助创作，页面已标注；不是历史照片。若组委会另有 AI 素材补充要求，提交前应据此调整。手册要求的完整版/匿名版、队员信息和最终打包，由全队整合时补齐。

## 依赖及用途

**运行依赖：无。** `server.mjs` 仅用 Node.js 内置模块提供本地预览，不参与网页交互，不构成后端业务。`tools/check.mjs` 使用 Node.js 内置模块检查脚本语法、本地资源引用和事件资料完整性。制作素材时用 Sharp 做图片格式转换；它不是作品运行依赖。预览测试使用 Playwright CLI；不随作品加载。

本地字体：**站酷小薇体**用于阶段名与筛选，**文楷**用于简介、地点及正文，**思源宋体600字重**用于按钮、导航及阅读短标题，**Oswald**用于年份；品牌及邮局题字保留志莽行书。均按 SIL Open Font License 1.1 分发，许可和来源在 `assets/fonts/`。网页加载轻量本地字形子集，不请求字体 CDN；字体不是预设网页样式或 UI 组件库。

阶段名称现优先使用八幅原创飞白艺术字，列表与详情共用，站酷小薇体作为文字回退。真实标题保留在页面中；图片与完整提示词见 [阶段题字记录](docs/STAGE-TITLE-ART.md)。山河邮局采用原生 SVG 立体邮箱，投递时依次开门、信封投入、合门、升旗，支持跳过及减少动态效果设置。

八幅阶段主题插画存放在 `assets/images/illustrations/`，铺作阶段背景，以约80%不透明度和局部浅色遮罩兼顾画面与文字。插画为解释性绘画，详情现址照片和史实时间线独立保留。生成工具、提示词及路径见 [插画记录](docs/ILLUSTRATIONS.md)；首页和栏目题字记录见 [题字记录](docs/TITLE-ART.md)。
